# v0.8.0 — Whanganui Crosswater and V8 Sound Lab

## Course

Whanganui Crosswater is an original, widened interpretation of **Shelter View, Whanganui**, using the venue's official public [site-plan reference](https://www.v8jetsprints.co.nz/shelter-view-site-map) and [gallery](https://www.v8jetsprints.co.nz/gallery). Searches for a New Zealand jetsprint course named Shelley/Shelly Beach did not provide a verifiable layout, so Shelter View was selected instead. The reference artwork, photographs, labels, logos and branding are not included in the application.

The track follows the reference's elongated outline, western return, irregular island network, interior links and eastern return. It is an approximation for play, with wider channels, revised proportions and omitted tiny islets. It is not a surveyed recreation or an official race rotation.

Edit **`src/course-layout.js`** to refine named junctions and individual centripetal Catmull–Rom spline control points. The 11 waterways are independent of the single prescribed rotation in `src/course.js`. Ordered directional gates, wrong-turn recovery, navigator arrows and five-lap timing remain in their existing systems. Changed course IDs keep historical scores separate without deleting them.

Water, banks, land and fluid bathymetry use the same channel network. Cached capsule unions make one continuous water surface with holes for islands. Clipped land replaces the coarse rectangular shoreline grid; subdivided banks rise smoothly to the land. `src/hull-collision.js` checks the bow, stern and beam after each existing physics substep. It changes motion only on bank contact. Throttle-dependent steering, handling defaults, camera calculations and controls retain their existing code.

## Sound Lab

Open **V8 SOUND LAB** on the right. There are 32 live numerical sliders in four collapsible groups, with Marine Jet Sprint V8 as the default. The other factory voices are Big Cam V8 Idle, Naturally Aspirated Race V8 and Open Headers V8. Any slider adjustment selects Custom. Reset sound restores Marine defaults.

**Start engine test** unlocks browser audio and holds the boat, countdown and race clock. The test throttle accepts 0–100%. Stopping restores the held boat velocity and resumes normal racing. Restart stops the test. Test mode and test throttle are intentionally not persisted. Blur/backgrounding releases controls and test throttle and suspends audio; a fresh test button or throttle gesture can resume audio.

### Start here for a deep, loping idle

| Control | Useful starting range | Audible effect |
| --- | --- | --- |
| Idle RPM | 800–950 RPM | Slower, individually perceptible firing cadence |
| Camshaft lope intensity | 75–95% | Stronger rhythmic exhaust surging and bounded timing modulation |
| Pulse duration | 40–55 ms | Longer, rounder exhaust body |
| Exhaust bass | 70–90% | More low exhaust weight |
| Low-frequency rumble | 60–85% | More crank/cycle rumble beneath firing pulses |
| Exhaust resonance | 60–80% | Longer low exhaust ringing |
| Pulse irregularity | 20–35% | Mild cycle variation; high values can obscure the cadence |
| Pulse sharpness / rasp / distortion | Keep moderate | Lower settings favor round glugs over bright edges |

A phone speaker cannot reproduce the deepest bass; headphones or a speaker with bass extension are useful for judging these controls. Sound character still needs listening checks on actual iPhone Safari hardware.

## Audio implementation

`v8-core.js` runs in `v8-worklet.js` on the audio thread. It schedules eight combustion events per 720 crank degrees (RPM/15 events per second), with cross-plane bank grouping for firing order 1-8-4-3-6-5-7-2. Lope uses bounded amplitude/timing modulation and cycle variation without dropping cylinders. Pulse envelopes excite low exhaust and growl resonators; crank sine layers, combustion-gated noise, mechanical vibration, water noise and restrained overrun crackle add texture. RPM/throttle/load transitions are separate from physics.

A fixed Web Audio graph adds bass/mid/treble EQ, muffler filtering, smoothly crossfaded saturation, a filtered reflection delay, camera-distance attenuation, compression, limiting and a bounded output ceiling. DSP parameter smoothing and AudioParam ramps avoid slider steps. Editing settings does not create audio nodes. A single ScriptProcessor compatibility fallback is used if AudioWorklet is unavailable; production should use HTTPS and the worklet path on current Safari.

For future **licensed recordings**, connect decoded sample sources to `engine.sampleInput` after `await engine.start()`, drive their playback/crossfade from `engine.rpm` and `engine.load`, and call `engine.setSampleBlend(0..1)`. Synth and samples share tone controls, master mute, compression and the output ceiling. No external recorded engine material is included.

## Persistence and compatibility

Audio uses `jet-sprint-v8-audio-v1` and `jet-sprint-v8-presets-v1`. Physics/game settings, existing saved tuning presets and score keys are unchanged. Save Preset and Load Preset manage named audio configurations; entering an existing name and saving replaces that named audio preset. JSON export includes all 32 positions and schema/type markers. Import validates atomically, clamps numeric bounds and rejects unrelated physics JSON. File import and a pasteable JSON box are supported; unavailable storage retains live tuning and reports an export-backup warning.

## Validation

Run `npm test` and `npm run build`. Tests cover five laps driven with binary controls and the unchanged steering integrator, ordered gates, drift crossings, wrong branches, shoreline clearance, hull contacts, settings preservation, idle/redline DSP bounds, live parameter smoothing, firing cadence and configurable RPM response. `test/sound-lab-browser.html` exercises audio/UI without WebGL. This development environment's cloud browser has WebGL disabled, so full rendered gameplay and physical iPhone performance/listening remain device checks.
