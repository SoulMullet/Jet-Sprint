# JET SPRINT interface fonts

The fonts are bundled locally; the game never requests a font service.

- **Barlow Condensed ExtraBold Italic / SemiBold** — Copyright 2017 The Barlow Project Authors (https://github.com/jpt/barlow). SIL Open Font License 1.1; see `Barlow-OFL.txt`.
- **IBM Plex Mono Regular** — Copyright © 2017 IBM Corp., reserved font name “Plex”. SIL Open Font License 1.1; see `IBMPlexMono-OFL.txt`.

Unmodified font outlines from https://github.com/google/fonts/tree/main/ofl/barlowcondensed and https://github.com/google/fonts/tree/main/ofl/ibmplexmono, retrieved October 29, 2026. TTF files were losslessly compressed to WOFF2 with fontTools; no glyphs were edited or subsetted. Full copyright and license notices are distributed alongside the font files.

The JET SPRINT wordmark arrangement, stripes, course diagram, favicon and interface SVG symbols are original project artwork.
